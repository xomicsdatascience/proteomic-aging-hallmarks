# Protein and pathway inference

The model uses 1,004 primary assay observations and 7,871 retained features, with design rank 173. Empirical Bayes prior: d0=2.89001, s0 squared=0.0204079. Protein tests require at least three observed values in each contrasted group.

At BH q < 0.05 across 2,254 compound-program hypotheses, the primary matched-plate mean-response analysis identifies 751 pairs. The secondary fixed-correlation CAMERA-PR-style analysis identifies 509 pairs, and the pairwise empirical-correlation sensitivity identifies 0 pairs. These analyses have different assumptions and weights. NES is descriptive. Direct kinase comparisons have their own testing family.

Plate-response inference assumes independent plates. Fixed treatment coordinates, incomplete culture provenance, and observed vehicle-position differences limit interpretation; see A04 and A06. Neither discovery counts nor correlation sensitivity establish calibrated whole-screen error control or beneficial aging effects.
